# tidyversindonesia 0.1.0

* Rilis awal paket `tidyversindonesia`.
* Menyediakan fungsi-fungsi Tidyverse dengan nama dalam Bahasa Indonesia.
* Mengadaptasi alur proses data science:
  Import → Tidy → Transform → Visualize → Model → Communicate
* Mencakup fungsi dasar untuk baca data, rapi data, transformasi, visualisasi, dan model regresi sederhana.

# Melihat nama kolom

Padanan fungsi \`names()\`

## Usage

``` r
data_lihat_nama(data)
```

## Arguments

- data:

  Data frame

## Value

Vektor karakter berisi nama kolom

## See also

\[base::names()\]

## Examples

``` r
data_lihat_nama(penguin)
#> [1] "spesies"       "pulau"         "panjang_paruh" "tebal_paruh"  
#> [5] "panjang_sirip" "massa_tubuh"   "jenis_kelamin" "tahun"        
```

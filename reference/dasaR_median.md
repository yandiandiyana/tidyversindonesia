# Menghitung nilai median

Padanan fungsi \`median()\`

## Usage

``` r
dasaR_median(x, ...)
```

## Arguments

- x:

  Vektor numerik

- ...:

  Argumen tambahan untuk \`median()\`

## Value

Nilai median

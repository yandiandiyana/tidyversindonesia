# Menghitung standar deviasi

Padanan fungsi \`sd()\`

## Usage

``` r
dasaR_standar_deviasi(x, ...)
```

## Arguments

- x:

  Vektor numerik

- ...:

  Argumen tambahan

## Value

Nilai standar deviasi

# Mengubah direktori kerja aktif

Padanan fungsi \`setwd()\`

## Usage

``` r
data_direktori_simpan(path)
```

## Arguments

- path:

  String path direktori baru

## Value

Path baru setelah diubah

## See also

\[setwd()\], \[getwd()\], \[direktori_lihat()\]

## Examples

``` r
if (FALSE) { # \dontrun{
data_direktori_simpan("C:/Users/Username/Documents/Proyek")
} # }
```

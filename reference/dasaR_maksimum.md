# Mengambil nilai maksimum

Padanan fungsi \`max()\`

## Usage

``` r
dasaR_maksimum(x, ...)
```

## Arguments

- x:

  Vektor numerik

- ...:

  Argumen tambahan

## Value

Nilai maksimum

# Memotong baris bagian awal (kepala)

Padanan fungsi \`dplyr::slice_head()\`

## Usage

``` r
transformasi_potong_kepala(data, n = NULL, prop = NULL)
```

## Arguments

- data:

  Data frame atau tibble

- n:

  Jumlah baris

- prop:

  Proporsi baris

## Value

Data frame

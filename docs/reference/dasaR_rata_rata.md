# Menghitung nilai rata-rata

Padanan fungsi \`mean()\`

## Usage

``` r
dasaR_rata_rata(x, ...)
```

## Arguments

- x:

  Vektor numerik

- ...:

  Argumen tambahan untuk \`mean()\`

## Value

Nilai rata-rata

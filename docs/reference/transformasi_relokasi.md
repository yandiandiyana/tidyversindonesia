# Relokasi kolom dalam data

Padanan fungsi \`dplyr::relocate()\`

## Usage

``` r
transformasi_relokasi(data, ..., .before = NULL, .after = NULL)
```

## Arguments

- data:

  Data frame

- ...:

  Kolom yang ingin dipindahkan

- .before:

  Kolom tujuan sebelum posisi relokasi

- .after:

  Kolom tujuan setelah posisi relokasi

## Value

Data frame dengan kolom yang sudah dipindah

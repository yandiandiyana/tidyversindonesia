# Melihat dimensi data (jumlah baris dan jumlah kolom)

Padanan fungsi \`dim()\`

## Usage

``` r
data_lihat_dimensi(data)
```

## Arguments

- data:

  Data frame

## Value

Vektor numerik: jumlah baris dan kolom

## See also

\[base::dim()\]

## Examples

``` r
data_lihat_dimensi(penguin)
#> [1] 344   8
```

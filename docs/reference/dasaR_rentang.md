# Menghitung nilai rentang

Padanan fungsi \`range()\`

## Usage

``` r
dasaR_rentang(x, ...)
```

## Arguments

- x:

  Vektor numerik

- ...:

  Argumen tambahan

## Value

Vektor panjang 2 berisi nilai minimum dan maksimum
